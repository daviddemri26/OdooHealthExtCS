# OdooHealthExtCS v1.0.0

The first team-ready release brings the required Account health and customer Industry updates directly into Odoo subscription records.

## Highlights

- Set or clear Low, Medium, and High account health while preserving unrelated tags.
- Search and update the exact linked customer's industry without leaving the subscription.
- See selections immediately, with automatic visual rollback if Odoo rejects a write.
- Undo recent successful changes without overwriting a later external update.
- Choose Auto, Light, or Dark appearance and control each feature and its success confirmations.
- Use the same focused interface in Chrome/Chromium and Firefox.

## Privacy and scope

The extension runs only on `https://www.odoo.com/odoo*`, uses the current authenticated Odoo session, and sends no Odoo page data to external services. It requests only browser storage for preferences and a sanitized compatibility status.
