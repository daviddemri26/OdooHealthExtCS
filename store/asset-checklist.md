# Screenshot and Promotional Asset Checklist

## Nonnegotiable privacy checks

- [ ] Use sanitized synthetic fixtures or an approved noncritical demo record.
- [ ] No supplied development captures or HTML exports are reused.
- [ ] No real customer/company/person name, address, email, phone, ID, order number, invoice, MRR, project, database, or sidebar history is visible.
- [ ] No browser profile, notification, tab title, bookmark, system menu, or unrelated app content is visible.
- [ ] No cookies, developer tools, network panels, credentials, or internal URLs beyond the allowed Odoo path are visible.
- [ ] A second reviewer confirms the exported pixels, filename, and metadata are safe.

## Required scenes

- [ ] Subscription with Account health not set.
- [ ] Active High/Medium/Low state with subdued inactive controls.
- [ ] Industry and Health aligned above Order Date, plus the open searchable dropdown with sanitized choices.
- [ ] Settings popup with feature and appearance controls.
- [ ] One light-mode and one dark-mode composition.

## Store formats

- [ ] Chrome screenshots meet current dimensions and count requirements.
- [ ] Firefox screenshots meet current dimensions and count requirements.
- [ ] Promotional tiles are created only if the store requests them.
- [ ] Final purple O/green cross icon has a pure white softly rounded square and is reviewed at 16, 32, 48, 96, 128, 256, and 512 px.
- [ ] Text remains readable without claiming official Odoo affiliation.
