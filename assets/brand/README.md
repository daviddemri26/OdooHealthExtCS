# Brand asset contract

The approved source icon lives at `odoo-health-ext-cs-icon.svg`. It is a transparent Odoo-purple
letter O with a green cross inside. The packaging pipeline derives every browser and store PNG from
this SVG and refuses a tagged release when the source is missing.

The original parallel-design deliverables remain in `/icons` for provenance. Do not replace the
canonical SVG without product approval.
