Privacy policy

OdooHealthExtCS is an internal browser productivity extension for authorized Odoo Customer Success users. It is not an installable Odoo module and is not an official Odoo product.

Data processed

On matching Odoo subscription pages, enabled features read only the fields needed for account health and the exact linked customer's industry. User-requested updates are sent back to Odoo through the browser's current authenticated same-origin session.

Processing occurs in the browser and between the browser and www.odoo.com. No Odoo page data is sent to the developer, analytics providers, advertising networks, or other external services.

Data stored

Browser storage contains only feature and appearance preferences plus a sanitized compatibility code and timestamp. The extension does not store Odoo records, customer data, cookies, passwords, CSRF values, session identifiers, credentials, request histories, or raw server stack traces.

Permissions

The storage permission saves settings and compatibility status. The content script is limited to https://www.odoo.com/odoo*. No history, tabs, cookies, identity, downloads, clipboard, camera, microphone, geolocation, or broad host permission is requested.

Sharing and advertising

The extension does not sell, rent, monetize, advertise with, profile, or share user or customer data. It contains no analytics, tracking SDK, or remotely hosted executable code.

User control and retention

Users may disable features, clear extension storage, or uninstall the extension. Clearing storage removes preferences and compatibility status. Requested Odoo record changes remain subject to Odoo and organizational retention policies.

Security and changes

The project minimizes permissions, validates model contracts before writes, sanitizes errors, and scans releases for prohibited sensitive material. Material policy changes will be reflected on this page and in the public repository.

Contact

Use the support process for privacy questions. Never include customer or session data.
