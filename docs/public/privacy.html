Privacy policy

OdooHealthExtCS is an internal browser productivity toolbox for authorized users. It is not an installable Odoo module and is not an official Odoo product.

Data processed

The extension processes only the limited workspace context needed to display enabled tools and complete actions explicitly requested by the user. Workspace content is not sent to the developer, analytics providers, advertising networks, or other external services.

Data stored

Browser storage contains only extension preferences and basic operating status. The extension does not persist workspace records, customer content, credentials, or generated links.

Permissions

Browser permissions are limited to saving preferences, accessing the supported workspace, and completing explicit shortcut actions. The extension does not request broad access to unrelated browsing activity or device sensors.

Sharing and advertising

The extension does not sell, rent, monetize, advertise with, profile, or share user or customer data. It contains no analytics, tracking SDK, or remotely hosted executable code.

User control and retention

Users may disable tools, clear extension storage, or uninstall the extension. Clearing storage removes preferences and compatibility status. Actions completed in the workspace remain subject to the organization's normal retention policies.

Security and changes

The extension is designed to minimize access and data use. Material privacy changes will be reflected on this page.

Contact

Use the support process for privacy questions. Never include customer or session data.
