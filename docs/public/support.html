Help and troubleshooting

Support

OdooHealthExtCS version 1 runs only on https://www.odoo.com/odoo* for authorized internal users.

Quick checks

  1. Confirm you are signed in and viewing an Odoo subscription form.
  2. Open the extension popup and enable the master and relevant feature switches.
  3. Reload the Odoo tab after installing or updating the extension.
  4. Confirm your Odoo user can make the same update in the native interface.

Request support

Open an issue in the GitHub repository with the extension version, browser/version, sanitized compatibility code, approximate time, and reproduction steps.

Protect customer data. Do not attach real customer screenshots, HTML or network exports, cookies, credentials, session values, names, contact details, or record IDs. Use a sanitized fixture or approved demo record.

Security reports

Do not report vulnerabilities in a public issue. Use the repository's private GitHub Security Advisory reporting form.

Common issues

Missing controls usually indicate a nonmatching URL, a non-subscription route, or disabled settings. “Extension connection unavailable” normally requires reloading the extension and then the Odoo tab. A timeout means the bridge loaded but Odoo did not complete the request. Missing health tags or changed Odoo fields intentionally disable writes. An expired session requires signing in again; the extension never stores or refreshes credentials.
