Internal help

Support

OdooHealthExtCS version 2.0.2 is an internal browser toolbox for authorized users.

Quick checks

  1. Confirm you are signed in and viewing a supported workspace page.
  2. Open the extension popup and enable the desired tool.
  3. Reload the workspace tab after installing or updating the extension.
  4. If the issue persists, contact the internal maintainer.

Request support

Use the approved internal support channel. Include the extension version, browser version, approximate time, and brief reproduction steps.

Protect customer data. Do not attach real customer screenshots, HTML or network exports, cookies, credentials, session values, names, contact details, or record IDs. Use a sanitized fixture or approved demo record.

Security reports

Report security concerns only through the approved private internal channel. Do not publish vulnerability details.

Common issues

Reload the extension and workspace tab after an update. If the toolbox remains unavailable, use the internal support process without sharing customer data.
